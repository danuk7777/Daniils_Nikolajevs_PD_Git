# Pozitīvo pāra skaitļu summa

Šī programma aprēķina visu pozitīvo pāra skaitļu summu no 1 līdz lietotāja ievadītajam skaitlim n.

Lietotājs ievada veselu skaitli, un programma saskaita visus pāra skaitļus līdz šim skaitlim, ieskaitot to, ja tas ir pāra skaitlis.

Python faila nosaukums: para_skaitlu_summa.py
